HOW TO UPDATE / DEPLOY THE WFMU EXPLORER (v2.0)
================================================

Server: AWS t3.small (2 vCPU, 2 GB RAM), Ubuntu, open-source Shiny Server.
App dir: /srv/shiny-server (root-owned; the app runs as user `shiny`).
Log in with PuTTY.


ROUTINE UPDATE (code and/or data)
---------------------------------
Locally: make sure playlists.parquet, djKey.parquet, djsimilarity.parquet,
distinctive_artists.parquet, djdtm.rdata and similarity_histogram_gg.rdata are
up to date, then git push.

On the instance:
  cd /srv/shiny-server
  sudo git pull
  sudo systemctl restart shiny-server
  sudo ss -plut | grep -i shiny        # confirm it's listening

Notes:
* The app keeps a persistent cache (song search index, histogram bins, memoised
  query results) keyed by the newest data-file modification time. A git pull
  that changes any data file makes the app rebuild the cache on its next start
  (adds ~2 s once); old cache directories are deleted automatically.
* If you change how a query WORKS (not just the data), bump CACHE_VERSION in
  app.R so stale cached results are discarded.
* First start after a reboot is slow (10-20 s) while package files come off
  disk; later starts are ~2-3 s.


ONE-TIME SERVER SETUP FOR v2.0
------------------------------
1) Cache directory writable by the shiny user:
  sudo mkdir -p /var/cache/wfmu_explorer
  sudo chown shiny:shiny /var/cache/wfmu_explorer

2) Tell the app where the cache is. Either (a) an .Renviron in the app dir
   (R reads it from the working directory at startup):
  echo 'WFMU_CACHE_DIR=/var/cache/wfmu_explorer' | sudo tee /srv/shiny-server/.Renviron
   or (b) a systemd override, inherited by the R processes:
  sudo systemctl edit shiny-server
     [Service]
     Environment=WFMU_CACHE_DIR=/var/cache/wfmu_explorer
  sudo systemctl daemon-reload
   If neither is set the app falls back to /home/shiny/.cache/R/wfmu_explorer,
   which also works.
   NOTE: do NOT delete .Renviron when re-cloning (see below).

3) /etc/shiny-server/shiny-server.conf -- inside the `location` block that
   serves the app (site_dir /srv/shiny-server):
     app_idle_timeout 0;      # keep the R process resident (default kills it
                              # after 5 idle minutes, so every visitor after a
                              # quiet spell paid the full startup)
     app_init_timeout 120;    # headroom for cold starts (default 60)
     preserve_logs true;      # keep logs of clean exits so startup messages
                              # ("Cache dir:", "New channel(s)") are findable
  sudo systemctl restart shiny-server
   Memory: the resident process is ~500-700 MB; fine on 2 GB with this single app.

4) Verify:
  grep "Cache dir" /var/log/shiny-server/*.log     # expect /var/cache/wfmu_explorer/v2.0_<stamp>
  sudo less "$(ls -t /var/log/shiny-server/*.log | head -n 1)"   # most recent startup log


FRESH CLONE INTO /srv/shiny-server
----------------------------------
  cd /srv/shiny-server
  ls -a                                    # dir must be empty except hidden files
  sudo rm -rf .Rprofile .git .gitignore .Rhistory .Rdata   # NOT .Renviron
  sudo git clone -b master --single-branch https://github.com/apsteinmetz/wfmu_explorer.git . --depth 1
Then redo step 2 above if .Renviron is missing.


ERROR LOGS
----------
  ls /var/log/shiny-server/*.log
  /var/log/shinyserver.log
  sudo less "$(ls -t /var/log/shiny-server/*.log | head -n 1)"


SYSTEM PACKAGES YOU MAY NEED
----------------------------
  sudo apt-get install gfortran gcc g++ make libblas-dev liblapack-dev zlib1g-dev


R PACKAGES REQUIRED (v2.0)
--------------------------
Install as root so they land in the site library:
  sudo su - -c "R -e \"install.packages(c(
    'dplyr','duckdb','duckplyr','shiny','shinycssloaders','shinythemes',
    'memoise','cachem','wordcloud2','htmlwidgets','htmltools','lubridate',
    'igraph','circlize','RColorBrewer','stringr','ggplot2','ggthemes','zoo',
    'tm','DT'))\""

No longer used (removed in 2.0): rvest, jsonlite (still installed as a shiny
dependency), gt, tidyr, bslib (pulled in by shiny anyway), xts, rmarkdown, renv.
